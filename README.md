# Sales Data Analysis Project

## Project Overview
This project focuses on analyzing sales data using Python to identify business trends, evaluate sales performance, and generate meaningful insights through data analysis and visualization.

## Objectives
- Analyze overall sales performance.
- Identify top-performing product lines.
- Evaluate country-wise revenue contribution.
- Analyze yearly and monthly sales trends.
- Understand deal size distribution.
- Identify and handle missing values in the dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Visual Studio Code

## Dataset Information
The project uses a sales dataset containing information about:
- Order Number
- Sales
- Order Date
- Product Line
- Product Code
- Customer Name
- Country
- Territory
- Deal Size
- Quantity Ordered

## Project Workflow

1. Data Loading
2. Data Exploration
3. Data Cleaning and Preprocessing
4. Missing Value Analysis
5. Sales Performance Analysis
6. Product and Country-wise Analysis
7. Yearly and Monthly Sales Analysis
8. Data Visualization
9. Business Insights Generation

## Key Findings

- **Total Sales:** $10,032,628.85
- **Total Orders:** 307
- **Units Sold:** 99,067
- **Average Order Value:** $32,679.57
- **Top Product Line:** Classic Cars
- **Top Revenue-Generating Country:** USA
- **Best Sales Year:** 2004
- **Best Sales Month:** November 2004
- **Highest Revenue Deal Size:** Medium (60.7%)

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Open `Sales_Analysis.ipynb`.
5. Select the appropriate Python kernel.
6. Run all notebook cells.
